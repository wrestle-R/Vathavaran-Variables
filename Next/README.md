# Web workspace

Browse your GitHub repositories, upload encrypted environment versions, and
open or download the configuration you need.

[Open the workspace](https://vathavaran-variable.vercel.app) ·
[Read the web guide](https://vathavaran-variable.vercel.app/docs/guides/web)

Sign in with your own GitHub account. Reading files requires repository access;
uploading requires write access. Earlier versions remain available after an upload.

The website defaults to dark mode. The header theme button switches to light mode.
Keep downloaded files and copied configuration private, and sign out after using
a shared device.
